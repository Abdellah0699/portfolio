E-Commerce Demo

An editorial fashion storefront, front end only.

e-commerce-demoo.netlify.app
Overview

A demo e-commerce storefront built around a moody, night-shot fashion brand — product browsing, a cart, and a checkout flow, entirely on the front end with no real backend or payment processing behind it.

The Idea

I wanted to practice the interaction patterns that make an e-commerce site actually feel like one — product grids, cart state, category browsing — without needing a real store behind it. Building a fictional brand gave me the freedom to focus entirely on the front end.

What I Built
  • A horizontal, drag-to-explore collections carousel
  • Product grids with add-to-cart interactions
  • A cart drawer that tracks a running subtotal
  • Category browsing (New Arrivals, Tops, Bottoms, Outerwear, Accessories)
  • A search overlay
Design

The art direction leans into an after-dark, editorial fashion look — large type for seasonal drops, dark imagery, and a horizontal-scroll collections section that feels closer to a lookbook than a typical storefront grid.

Technology

Built entirely with plain HTML, CSS and JavaScript, deployed on Netlify. Cart state and UI interactions are handled client-side — there's no backend or real payment processing behind the checkout.

  • HTML
  • CSS
  • JavaScript
Challenges

Managing cart state — adding items, updating quantities, keeping the subtotal correct — without a framework meant being deliberate about how state and the DOM stayed in sync. Getting the drag-based collections carousel to feel smooth, rather than janky, took a few iterations, as did keeping product image grids performant on lower-end connections.

What I Learned

This project pushed me to structure cart logic and UI state cleanly in vanilla JavaScript, build a drag interaction from scratch, and commit to a distinct art direction instead of a default e-commerce look.
