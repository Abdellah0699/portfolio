WortKarte

Language-learning web application.

wortkarte-official.netlify.app
Overview

WortKarte is a language-learning web application built to help users practice and build German vocabulary, with a terminal-inspired interface instead of a typical app layout.

The Idea

Most vocabulary apps bury the actual practice under accounts, streak pressure and ads. WortKarte strips that away: pick a level from A1 to C2 and start practicing straight away, no sign-up required.

Instead of a typical app layout, it borrows the look of a command line — a small nod to the fact that it was built by a developer, for anyone who wants a fast, no-friction way to practice.

What I Built
  • Level-based vocabulary practice covering CEFR levels A1 through C2
  • A progress counter per level, so it's clear how far through a level a user is
  • Progress saved locally on the user's device via the browser, with no accounts, ads or tracking
  • A terminal-inspired interface, down to the command-style prompt text
Design

The whole interface leans into a CLI aesthetic — monospace type, a blinking cursor, and copy phrased like commands rather than app menus. It's a deliberate departure from the usual language-app look, aimed at making practice feel quick and a little less precious.

Technology

Built with plain HTML, CSS and JavaScript, with no framework and no backend — progress is kept entirely in the browser.

  • HTML
  • CSS
  • JavaScript
Challenges

Keeping everything client-side meant paying real attention to how progress gets stored and restored reliably in the browser, without a database to fall back on. Structuring vocabulary content by CEFR level in plain JavaScript, in a way that stayed easy to extend, took a few passes to get right.

What I Learned

WortKarte was a chance to design something with a strong, specific visual identity instead of a generic layout, and to think through level-based content and local persistence without reaching for a backend.
