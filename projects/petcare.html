PetCare

Pet-care management web application.

petcare-official.netlify.app
Overview

PetCare is a full-stack web application that gives pet owners one place to manage everything involved in looking after a pet — appointments, medication, grooming, food, weight and expenses.

The Idea

Pet care tends to live in too many places at once — a vet reminder in one app, a grooming date on a calendar, a medication schedule kept in someone's head. It's easy for something to slip.

PetCare brings all of it into a single, calm view, with reminders that reach an owner's inbox before they need them, not after.

What I Built
  • Account creation and login with JWT-based authentication and bcrypt password hashing
  • Pet profiles with photo, breed, age and weight
  • One-time and recurring reminders, with email alerts sent through Resend on a schedule handled by APScheduler
  • Vet appointment tracking, with notes and history
  • Medication tracking — dosage, frequency, and a log of doses given
  • Grooming schedule with the next due date always visible
  • Food tracking with reorder reminders
  • Weight tracking with a simple history
  • Expense tracking by pet and category
  • A free tier and a Pro tier with live PayPal subscriptions ($5.99/month or $49/year)
Design

The interface is built around a calm dashboard rather than a busy one — one pet profile, one clear list of what's due, and settings that stay out of the way until needed. Onboarding is deliberately short: create an account, add a pet, then start adding reminders and routines as they come up.

The layout is fully responsive, since most reminders end up being read on a phone rather than a desktop.

Technology

Frontend built with plain HTML, CSS and JavaScript, deployed on Netlify. Backend built with Python (FastAPI), deployed on Railway, backed by a Railway-hosted PostgreSQL database.

  • HTML
  • CSS
  • JavaScript
  • Python
  • FastAPI
  • SQL / PostgreSQL
Challenges

Getting authentication right — password hashing, token handling, and making sure sessions behaved correctly — took more care than it looks like from the outside. Scheduling recurring email reminders reliably, and getting a live payment integration working end to end with PayPal, both surfaced real deployment issues that only showed up once the app was actually running in production rather than on a local machine.

What I Learned

Building PetCare end to end meant designing an authentication system I'd actually trust, wiring up scheduled jobs, and integrating a real payment provider — not just the parts that are easy to demo. Fixing things that only broke in production taught me more than any tutorial could.
